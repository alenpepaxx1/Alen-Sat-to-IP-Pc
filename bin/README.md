Place a trusted FFmpeg build here as `ffmpeg.exe` (Windows) or `ffmpeg` (macOS/Linux), or install it on PATH. The build must include libx264 and AAC encoding. FFmpeg binaries are not bundled.
Official download entry point: https://ffmpeg.org/download.html
The bridge launches a fixed argument list without a command shell. It passes local RTP MPEG-TS payloads through stdin; FFmpeg does not open receiver-supplied URLs.
